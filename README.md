# robot_arm

Arduino Mega 2560용 평행링크 로봇팔입니다. X/Y 모터를 함께 구동하는
상대 직선 이동(mm)을 지원하며, Z 베이스는 기존 각도 명령을 사용합니다.

## 파일과 업로드

GitHub의 **Code → Download ZIP**으로 받거나 저장소를 clone하세요.
`robot_arm.ino`, `xy_control.h`, `xy_motion.h`, `z_homing.h`, `battery_approach.h`를 같은 `robot_arm` 폴더에 둡니다.
`.ino`만 복사하면 새 기능이 컴파일되지 않습니다.

Arduino IDE에서 보드는 **Arduino Mega or Mega 2560**, 프로세서는
**ATmega2560**을 선택합니다. 기존 `Wire` 및 `Servo` 라이브러리를 사용합니다.
시리얼 모니터는 **115200bps, 줄바꿈 전송**입니다.

## 기존 명령

| 명령 | 의미 |
| --- | --- |
| `x 1`, `y 1` | 해당 모터의 관절 출력각을 1도 상대 이동 |
| `z 10` | 베이스를 10도 상대 회전 |
| `e` | 기존 X/Y/Z 엔코더 출력 |
| `zero` | 기존 엔코더 카운터를 0으로 초기화 |
| `h` | D22/D23/D24 홈 스위치 상태 출력 |
| `homez` | Z에서 한 번 감지 후 +5도 후퇴, 떨어진 위치를 Z 영점으로 설정 |
| `o` / `open` | D10 그리퍼 100도 |
| `c` / `close` | 그리퍼 20도 |
| `angle 60` | 그리퍼를 지정 각도로 이동 |

기존 모터/엔코더 핀과 함수 본문은 유지했습니다. X/Y/Z 모두 실물에서
확인된 모터 9T → 출력 32T 기어비를 사용합니다. AS5600은 Z 모터축을 측정하며
출력각은 모터축 각도를 `32/9`로 나눕니다. 전원 ON/리셋 시 그리퍼는 기존처럼
100도 열림 명령을 받습니다.

## X/Y mm 명령

| 명령 | 의미 |
| --- | --- |
| `xyhelp` | 기준 등록 방법과 명령 안내 |
| `xycal A B SX SY` | 현재 실측 링크 각도와 방향 등록, 모터 이동 없음 |
| `pos` | 엔코더에서 계산한 링크 각도와 손목 관절 위치 |
| `xycheck 1 0` | 앞으로 1mm 이동의 펄스 수 미리 보기, 모터 이동 없음 |
| `xm 1` / `xm -1` | 끝단을 앞으로 / 뒤로 1mm |
| `ym 1` / `ym -1` | 끝단을 위로 / 아래로 1mm |
| `xy 1 1` | 앞으로 1mm, 위로 1mm인 목표점까지 직선 이동 |
| `!` | mm 이동 중 수신되면 X/Y 펄스 중단, 기준 등록 해제 |

`x`, `y`는 계속 **도 단위**입니다. mm 명령에는 `xm`, `ym`, `xy`를 사용합니다.
앞/뒤는 현재 베이스가 향한 팔의 수직 평면에서의 방향입니다. Z를 회전하면
이 평면도 회전하며, 책상에 고정된 전역 X/Y 좌표 명령은 아닙니다.

새 핀은 없습니다. Z 홈 스위치는 기존 D24를 사용하며 아래의 Z 호밍 절차를 지원합니다.
X/Y 스위치는 `h`로 확인하는 기능만 있으며, X/Y 자동 호밍·리밋 정지는 아직 없습니다.

## Z 호밍 시험

확인된 접근 방향은 **음수(-)**, 후퇴 방향은 **양수(+)**입니다.
Z 스위치는 COM → GND, NC → D24, `INPUT_PULLUP`입니다.
놓으면 LOW, 누르거나 배선이 끊기면 HIGH이며 기존 배선을 바꿀 필요는 없습니다.

1. `h`로 놓으면 LOW / 누르면 HIGH인지 먼저 확인합니다.
2. 팔·그리퍼가 회전할 공간을 확보하고 스위치에서 가까운 위치에서 시작합니다.
3. 시리얼 모니터 115200bps, 새 줄 설정으로 `homez`를 전송합니다.
4. 음수 방향으로 최대 30도 탐색하고, 첫 HIGH에서 즉시 펄스를 중단합니다.
   시작할 때 이미 HIGH이면 음수 탐색 없이 바로 후퇴합니다.
5. 양수 방향으로 5도 후퇴합니다. 후퇴 중 스위치가 흔들려도 계속 후퇴합니다.
6. 멈춘 뒤 200ms 기다리고, 최종 스위치 LOW와 AS5600 읽기 성공을 확인합니다.
7. **스위치에서 떨어진 최종 위치를 Z=0으로 설정합니다.** 이전의 접촉 위치 영점과 다릅니다.
8. `h`에서 Z LOW, `e`에서 Z 약 0도인지 확인합니다. 추가 후퇴 명령은 필요 없습니다.

모든 각도 제한은 기어비를 적용한 **베이스 출력축 기준 명령값**입니다.
기어 유격이 있으면 실제 베이스 후퇴량은 5도보다 작을 수 있습니다.
펄스 HIGH/LOW는 각각 4000µs이며 전체 호밍은 20초 이내여야 합니다.
접점 20ms 안정화 검사와 두 번째 음수 재접근은 제거했습니다.
`homez`는 전원 ON 시 자동 실행하지 않습니다. 기존처럼 시작 시 그리퍼는 100도로 열립니다.

정상 출력 순서는 다음과 같습니다. 시작할 때 눌려 있으면 SEEK는 생략됩니다.

```text
Z HOME: SINGLE TOUCH; ! stops; search max 30 DEG; timeout 20 s
Z HOME: SEEK -
Z HOME: CONTACT - stopped
Z HOME: BACKOFF +5 DEG (no re-approach)
Z HOME DONE: Z=0 DEG at released position; switch LOW
```

호밍 중 `!`를 전송하면 후퇴 중에도 펄스를 중단합니다. 다른 입력은 호밍 중 버립니다.
스위치를 못 찾거나 5도 후퇴 후에도 HIGH인 경우, AS5600 통신 실패, 시간 초과,
사용자 중단이면 `Z HOME ERROR: stopped; zero NOT set`을 출력하며 영점을 설정하지 않습니다.
`Reason:`으로 원인을 구분합니다. 고정된 5도보다 더 후퇴하도록 자동 재시도하지 않습니다.
단일 접점을 기준으로 하므로 순간 노이즈와 유격의 영향을 받을 수 있어,
원점 반복성은 실제 베이스 표시로 확인해야 합니다.
이때는 이전 영점을 새 홈으로 믿고 진행하지 말고 원인을 해결한 뒤 호밍을 다시 실행합니다.
스위치를 못 찾으면 배선·접근 방향·시작 거리를 확인하고, 해제가 안 되면 NC 접점과
기계적 눌림을 확인하세요. I²C 통신은 지원되는 Wire에서 25ms 타임아웃을 적용했습니다.

일반 `z` 음수 이동도 매 펄스 전에 D24를 검사하여 HIGH이면
`Z HOME LIMIT: negative motion stopped`를 출력하고 중단합니다.
양수 후퇴는 허용합니다. 이 기능은 **홈 쪽 한 방향의 리밋**이며 반대쪽 회전 한계는
아직 정해지지 않았습니다. `!` 정지는 `homez`와 mm 이동에서만 처리합니다.
펄스 중단은 모터 전원이나 유지 토크를 끄는 동작이 아닙니다.

## 먼저 현재 자세 등록

전원 재인가 때마다 측정한 자세를 등록해야 mm 이동을 허용합니다.
등록값은 EEPROM에 저장하지 않습니다. 실제 자세를 모르는 상태에서 임의의
각도를 넣으면 계산이 틀려집니다. `zero`는 기구학적 각도를 알아내는 명령이 아닙니다.

- `A`: 베이스 쪽 주 관절 중심에서 중간 관절 중심으로 향하는 첫 링크의 **절대각**.
  Y 모터에 대응합니다.
- `B`: 중간 관절 중심에서 끝단 손목 관절 중심으로 향하는 둘째 링크의 **절대각**.
  X 모터에 대응합니다. 두 링크 사이의 상대각이 아닙니다.
- 두 각도 모두 앞쪽 수평을 0도, 위쪽 수직을 +90도, 뒤쪽 수평을 ±180도로
  정의합니다. 아래쪽을 향하는 링크는 음의 각도로 표현할 수 있습니다.
- `SX`: 기존 `x` 양수 명령으로 B가 증가하면 `1`, 감소하면 `-1`.
- `SY`: 기존 `y` 양수 명령으로 A가 증가하면 `1`, 감소하면 `-1`.

실제 자세를 측정한 뒤 `xycal A B SX SY`의 네 문자를 해당 숫자로 바꿔 전송합니다.
예를 들어 **실제로** A=60도, B=-30도이고 두 양수 명령이 각도를 증가시키는 경우에만
`xycal 60 -30 1 1`입니다. 이 숫자는 이 로봇의 홈 각도로 확정한 값이 아닙니다.
각도가 어떻게 대응하는지 확인한 뒤에는 다시 현재 자세를 측정하고 등록하세요.

등록 시 기존 X/Y 엔코더를 0으로 지우지 않고 그 순간 카운트를 기준으로 보관합니다.
`x`, `y`, `zero`, 정지 또는 추종 오차 발생 후에는 기준을 다시 등록해야 합니다.
`z`, 그리퍼, `h`, `e` 명령은 기준을 해제하지 않습니다.

X/Y 홈 스위치 설치 후에는 홈 자세에서의 실제 A/B와 접근 방향, 허용 관절 범위를
확정하고 자동 등록·리밋 기능을 연결해야 합니다. 기구학상 수평 0도와 홈 카운터 0은
다른 기준입니다.

## 기구학 및 움직임

원본과 동일한 두 주요 링크의 관절 중심 간 길이 120mm를 사용합니다.
기존 프로젝트 식의 `theta1`이 A이고, B는 `theta2 - 180도`와 같은 방향입니다.

```text
손목 앞뒤 위치 = 120 cos(A) + 120 cos(B)
손목 높이     = 120 sin(A) + 120 sin(B)
```

내부 삼각함수는 radian으로 계산합니다. 역기구학은 현재 조립 분기와 가까운
각도 해를 유지하며, 목표 경로를 먼저 검사한 뒤 0.5mm 이하 구간으로 나눕니다.
각 구간의 두 모터 펄스는 DDA 방식으로 같은 시간 안에 분배합니다. 구간마다
반올림 오차가 쌓이지 않도록 명령 시작점 기준 누적 펄스를 계산합니다.

그리퍼 방향과 장착 오프셋이 이동 중 일정하면 손목과 잡는 중심의 상대 변위는 같습니다.
`pos`는 **베이스 주 관절 기준 손목 위치**이며 건전지 중심이나 책상 높이가 아닙니다.
다리 36 → 60mm 변경과 그리퍼 오프셋은 고정된 평행이동이므로 상대 mm 이동량에는
영향이 없습니다. 건전지의 절대 좌표로 접근할 때는 해당 오프셋을 별도로 반영해야 합니다.

## 첫 시험 범위와 정지

- 한 명령의 직선 거리 최대 50mm, 각 링크 변화 최대 45도.
- 등록한 자세에서 각 링크가 ±60도를 벗어나는 경로는 거부합니다.
  이 범위는 초기 시험용이며, 실물의 충돌 없는 범위로 검증된 값은 아닙니다.
- 두 링크가 일직선으로 펴지거나 접히는 자세의 10도 이내를 피합니다.
- mm 이동 목표 속도 최대 40mm/s, 가속도 24mm/s²의 가감속을 사용합니다. 실제 속도는
  펄스 간격 제한, 인터럽트, I²C 읽기 등의 영향으로 더 느릴 수 있습니다.
- 구간마다 X/Y 엔코더와 누적 명령각을 비교합니다. 이동 중 1도, 종료 후
  200ms 대기한 시점에 0.25도를 넘는 추종 오차는 경고로 출력합니다.
  추종 오차만으로 명령 펄스를 중단하거나 XY 기준을 해제하지 않습니다.
  이동 중 경고가 발생했거나 종료 오차가 크면 추가 보정을 건너뜁니다.
  작은 종료 오차에 한해 엔코더 기준 목표 위치까지 저속 보정합니다.
  `XY CORRECT`가 출력되며 최대 3회, 회당 축별 최대 6펄스, 총 축별 최대
  15펄스로 제한합니다. 엔코더로 계산한 평면 위치 오차가 0.15mm 이내면
  `XY DONE`을 출력합니다. 오차가 줄지 않거나 한도 안에 수렴하지 못하면
  추가 보정만 끝내고 기준은 유지합니다. 이 경우 `XY FINISHED WITH WARNING`을
  출력하며 목표 도달 성공으로 취급하지 않습니다. `pos`와 다음 명령은 사용 가능합니다.
  모터가 실제로 멈춰도 요청한 펄스는 계속 출력되므로 이상 동작 시 `!`로 정지하세요.
  경로 계산 중 시작 위치가 0.15도 이상 변하면 움직이지 않고 기준을 유지합니다.
- mm 이동 중에는 시리얼 `!`만 처리하고 다른 입력은 버립니다. `!`는 기존
  `x/y/z` 각도 이동을 중단시키는 기능은 아닙니다.
- 펄스 중단은 드라이버 전원이나 모터 유지 토크를 끄지 않습니다.

펄스 분해능·기구 오차 때문에 실제 직선은 근사 경로입니다. 엔코더 결과 역시
모터축을 기준으로 계산하므로 기어 백래시, 링크 휨, 그리퍼 미끄러짐을 직접
측정하지 못합니다. 따라서 0.15mm는 엔코더 계산값의 종료 기준이며 실제 그리퍼의
정확도를 보장하는 값은 아닙니다. 중단된 이동을 자동으로 재시도하지 않습니다.

## 실제 시험 순서와 예상 출력

1. 건전지를 빼고 여유 있는 자세에서 기존 `x 1`, `y 1`로 링크 대응과 방향을 확인합니다.
2. 현재 A/B를 측정해 `xycal`로 등록합니다.
3. `xycheck 1 0`으로 계산 결과를 확인합니다. 이때는 움직이지 않습니다.
4. `xm 1`을 실행하고 앞뒤 변위와 높이 유지 여부를 측정합니다.
5. `xm -1`, `ym 1`, `ym -1`을 각각 시험한 뒤 `xy 1 1`을 시험합니다.
6. 짧은 이동에서 `!` 정지와 기준 해제를 확인합니다. 다시 측정·등록한 후 반복성을 확인합니다.

기준 미등록 상태에서는:

```text
ERROR: XY NOT CALIBRATED. Use xyhelp and xycal
```

정상적인 `xm 1` 실행의 출력 형식은 다음과 같습니다. 펄스 수와 측정값은 자세에 따라 다릅니다.

```text
XY MOVE: 1.000 mm forward, 0.000 mm up
X COMMAND PULSE: <부호 있는 펄스 수>
Y COMMAND PULSE: <부호 있는 펄스 수>
XY DONE (encoder-derived): FORWARD <측정값> mm, UP <측정값> mm
XY ERROR: FORWARD <오차> mm, UP <오차> mm
```

문제가 생기면 A/B를 상대 관절각으로 입력하지 않았는지, SX/SY가 맞는지,
기존 `e`에서 양수 명령에 엔코더 변화가 양수인지, 두 모터가 각각 해당 링크의
절대각을 제어하는지 확인하세요. `ENCODER FOLLOWING ERROR`가 나오면 기준을
반복 입력해서 억지로 진행하지 말고 모터 전원, 엔코더 배선·부호와 걸림을 확인합니다.
정상 출력이어도 실제 방향이나 거리가 다르면 각도 측정과 링크/그리퍼 기하를 확인해야 합니다.

## 건전지 위쪽 접근 시험 범위

X/Y 등록 자세 기준 시험 범위를 각각 ±60도로 확대했습니다. 50mm/명령,
45도/명령 제한과 특이 자세 회피, 엔코더 감시, 제한된 종료 보정 및 `!` 정지는 유지합니다.
이는 기구의 충돌 없는 범위를 보증하는 하드 리밋이 아닙니다.

보고된 A=18.213°, B=-77.723°에서 위로 30mm, 이어 앞으로 25mm의
경로를 5mm씩 나누어 모의 검증했습니다. 이상적인 최종 각도는 약
A=27.44°, B=-61.09°로 원래 등록 자세 (5°, -90°)의 ±60도 이내입니다.
실제 시험은 매 명령 완료 후 간섭 여부를 확인해야 합니다.

업로드하면 XY 기준이 초기화됩니다. 업로드 전후 팔이 전혀 움직이지 않은 경우에만
`xycal 18.213 -77.723 -1 1`로 위 보고 자세를 복원할 수 있습니다.
팔이 움직였다면 현재 각도를 다시 측정하거나 기존 사진 자세로 정확히 복원해야 합니다.
`xycal`은 이동하지 않으며, 등록 시점부터 ±60도 범위가 적용됩니다.

Z는 `z +5`에서 AS5600 RAW 변화가 약 -202인 실측에 맞춰
`Z_ENC_SIGN=-1`로 변경했습니다. 표시/계산 부호만 바꾸며 DIR, 호밍 방향,
32/9 기어비 및 RAW 누적 방식은 유지합니다.

50mm 제한은 전진/상승을 합한 직선 거리입니다. `xy 30 40`은 50mm지만
`xy 50 50`은 약 70.7mm여서 거부됩니다. 속도는 40mm/s이며,
50mm 이동에는 가감속을 포함해 이론상 약 2.9초 이상 걸립니다. `xycheck 50 0`으로 경로만 검사할 수 있습니다.
경로 검사는 실제 장애물을 감지하지 않습니다. 전원 차단 후 손으로 움직였다면
현재 자세를 다시 확인해 `xycal`로 등록해야 합니다.

## 저장 위치로 접근 (`above`)

사용자가 홈 실행 후 현장에서 조정한 최신 접근 자세를 펌웨어에 저장했습니다.
USB 재연결/재부팅에도 목표값은 유지되지만 현재 위치·XY 등록·호밍 상태는
자동 복구되지 않습니다.

| 지점 | A/Y | B/X | 앞으로 mm | 위로 mm | Z 출력각 |
|---|---:|---:|---:|---:|---:|
| 최신 접근 | 29.097 | -54.765 | 174.087 | -39.659 | 28.056° |
| 보정 집기 (로그 복원값) | 14.391 | -56.664 | 182.181 | -70.431 | 27.957° 부근 유지 |

이전 접근 Z=31.097° 대신, homez 후 z -2 / z -1로 정렬하고 측정한
28.056°를 사용합니다. `pick`은 최신 홈 기준 집기 기록을 사용하며 Z는 회전하지 않습니다.

재연결/업로드 후:

1. 무부하로 사진의 시작 자세에 X/Y를 맞춥니다.
2. `s` (`startpose`도 가능): 사진 추정 A=5°, B=-90°, SX=-1, SY=+1을 등록합니다. 실제 이동은 없습니다.
3. 회전 경로를 비우고 홈 탐색 가능한 위치에서 `homez`를 실행합니다.
4. `above`: 시작 자세에서 저장된 최종 관절각을 향해 **X/Y/Z 동시 이동**합니다.
5. `pos`, `e` 및 실물 정렬을 확인합니다. `above`는 하강·집기를 실행하지 않습니다.
6. 정렬 확인 후 별도로 `pick`을 실행하면 수정된 최종 집기 위치까지 X/Y를 동시에 움직이고 집게를 닫습니다.

`above`는 이전 명령 이력을 재생하지 않습니다. 시작/목표 관절각 사이를 같은
진행률로 보간하고, 세 축 펄스를 하나의 DDA 스케줄러로 분배합니다. 따라서 손목은
직선이 아닌 곡선을 그리며 Z도 동시에 회전합니다. 이전 상승→회전→전진 경로와
다르므로 첫 실물 시험에서 건전지, 받침, 배선과 간섭이 없는지 확인해야 합니다.
전체 보간 경로의 관절 범위 및 특이 자세를 먼저 검사하지만 장애물은 감지하지 못합니다.

X/Y 목표 속도는 12→40mm/s로 올리고 가속도는 8→24mm/s²로 변경했습니다. 자동 접근은
XY 손목 경로 길이로 펄스 시간을 계산합니다. Z 펄스 간격은 기존처럼 최소 8ms로
제한하므로 Z를 더 빠르게 돌리지 않습니다. 동기화 때문에 Z가 더 천천히 움직일 수
있으며 실제 소요 시간은 연산/I²C/인터럽트 영향으로 늘어납니다.
중간 10mm 정지·보정은 없고, 전체 이동 후 한 번의 제한된 XY 보정 단계만 있습니다.

XY/Z 각도 오차는 경고만 출력하고 명령을 중단하지 않습니다. 부족분을 무한 재시도하지
않습니다. 오차가 남으면 `ABOVE FINISHED WITH WARNING`과 엔코더 위치를 확인하고
수동 조정하세요. `!`, AS5600 통신 실패, 경로 거부는 중단 조건으로 유지합니다.
자동 명령을 중단하면 모든 PUL 핀을 LOW로 내리고 이후 동작을 수행하지 않습니다.
`pickinfo`는 저장 위치를 출력합니다. `pick`은 중간 조정 명령을 재생하지 않고
보정된 최종 관절각을 향해 한 번에 X/Y를 동기 이동합니다.

`tests/battery_approach_test.cpp`는 목표 펄스 수, XYZ 동시 진행, Z 최소 펄스 간격,
시작 조건 거부, 경고 후 진행, 유한 종료, 수동 정지, 센서 오류를 모의 검증합니다.
실제 로봇의 경로·속도·충돌 여부는 하드웨어에서 별도로 확인해야 합니다.

Z 목표 28.056°는 펌웨어 기본값으로 확정했습니다. 이제 `abovez` 없이
`s` → `homez` → `above` 순서로 실행합니다. 시작 사진 자세에 실제로
맞춘 상태에서만 `s`를 사용하세요. `abovez DEG`는 선택적인 임시
조정 명령이며, 재시작하면 28.056°로 돌아갑니다.

속도 변경은 경로 변경이 아닙니다. 동기화된 관절 보간 경로는 이전과 같아서
이미 관찰된 건전지와의 간섭을 해결하지 않습니다. 건전지를 치운 상태에서
속도를 먼저 확인하고 실제 접근에는 높이 확보 경로를 별도로 검증해야 합니다.

## 집기 명령 `pick`

`above` 후 실제 정렬을 확인하고 `pick`을 별도로 입력합니다. 시작 조건은
XY 기준 유효, Z 홈 완료 및 센서 정상, 저장 접근 위치에서 3mm 이내,
Z=27.957°에서 ±0.5° 이내입니다. 시작 자세에서 바로 `pick`을 실행하거나,
이미 집기 위치에 내려온 상태에서 재실행하면 움직이지 않습니다.

집게 열기 → 최종 A≈14.391°, B≈-56.664°까지 X/Y 동시 이동 → 집게 20° 닫기
순서입니다. `above`와 같은 DDA/가감속 방식이며 속도 목표는 40mm/s입니다.
보정은 마지막에만 수행합니다. 전체 관절 보간 경로를 먼저 검사하며 Z는 회전하지 않습니다.
이 경로는 손목의 직선 이동이 아닌 곡선이며, 이전 중간 지점 경로와 다릅니다.
첫 시험에서는 건전지/받침과의 간섭을 확인해야 합니다.
각도 오차만으로 중단하지 않는 기존 정책은 유지합니다. 경고가 남으면
`PICK FINISHED WITH WARNING`을 표시합니다. 이는 물체를 잡았다는 센서 확인이
아니라 닫기 명령을 실행했다는 뜻입니다. `!`, 경로 거부, 센서 실패가 발생하면
`PICK PAUSED`로 중단하고 닫기 명령은 실행하지 않습니다.

집은 뒤 `place`로 순서대로 들어 올리고 운반해 내려놓을 수 있습니다.
전체 실행 `run`은 Z 호밍 및 두 건전지 작업과 두 번째 반환까지 수행합니다.
최종 반환 후 후퇴/시작 자세 복귀는 실행하지 않습니다.
업로드 후에는 사진 시작 자세로 돌아가 기준을 등록하세요. 현재 집기 위치에서
`s`를 입력하면 잘못된 각도로 등록됩니다. `s`는 자동 복귀 명령이 아닙니다.

최신 집기 목표는 사용자가 전원을 끄기 전에 최종 pos/e를 남기지 못해 다음처럼
복원한 값입니다. 기준 pos=(183.125,-66.596)mm에 실제 출력 변위
(+0.018,-2.954), (-0.037,-0.867), (-0.925,-0.014)mm를 합산해
(182.181,-70.431)mm를 얻었습니다. 목표 IK는 기존 음수 굽힘 분기를 사용합니다.
표시 반올림 및 명령 사이의 움직임이 포함되지 않을 수 있으므로 최종 위치 직접
측정과 동등하다고 보장하지 않습니다. 재시작 시 사진 자세에서 s/homez 후 시험하세요.

## 운반·놓기 (`place`) 및 전체 한 번 실행 (`run`)

실제 내려놓고 집게를 연 최종 기록을 저장했습니다:
A=21.276°, B=-57.929°, 손목 앞으로 175.537mm / 위로 -58.144mm,
Z 출력각 50.081°. 사용자가 받침보다 약간 높은 곳에서 놓아도 안착하도록
설계했다고 확인했으므로 이 기록 위치에서 열고 멈춥니다.

운반 높이 UP=-12.027mm는 최종 UP=-58.144mm에서 이후 실측 이동량
(-20.042,-19.958,+4.994,-4.992,-0.013,-3.022,-3.084)mm를 역산한 값입니다.
중간 pos 직접 측정은 아니며 기록 반올림/정지 중 움직임이 누락될 수 있습니다.
최신 보정 집기 위치(-70.431mm)에서 약 58.4mm 상승하며, 과거 55mm 명령 합계보다
더 올라가지만 운반의 목표 높이를 유지하도록 한 것입니다.

`place` 순서:

1. 집게가 닫힌 집기 위치에서 Z를 유지하며 운반 높이까지 상승하는 동시에 5mm 뒤로 이동.
2. 상승 명령 완료 후 Z를 50.081°로 회전. X/Y는 유지.
3. 높이를 유지하며 목적지 반경으로 이동.
4. 기록된 내려놓기 위치로 하강.
5. 집게를 100°로 열고 종료. 후퇴/자동 복귀/반복 없음.

현재 위치가 저장 집기 위치에서 5mm 이내이고 Z가 27.957°에서 ±0.5° 이내,
XY 기준·Z 홈·AS5600이 정상이며 집게 닫기 명령 상태일 때만 `place`를 시작합니다.
집게 상태는 서보 명령값이며 실제로 건전지를 잡았는지 감지하는 센서는 없습니다.
운반용 자동 직선 이동은 최대 80mm를 한 번의 가감속으로 실행합니다.
수동 xm/ym/xy의 한 명령 제한은 50mm로 유지합니다. 각도 범위와 전체 경로 검사도 유지합니다.

재시작 시 사진 자세에서 `s`로 등록합니다:

- 첫 건전지만 단계별: `homez` → `above` → 확인 → `pick` → 확인 → `place`
- 전체: `run` (Z 호밍부터 두 번째 건전지 반환까지 한 번 실행)

`run`은 시작 자세를 확인한 뒤 Z 호밍을 자동 실행합니다. 기준 등록은 `s`로 별도 수행합니다.
호밍 실패 시 접근하지 않습니다. 명령 거부, `!`, 센서 오류 등으로
어느 단계가 끝나지 못하면 다음 단계는 실행하지 않습니다. 운반 중 중단 시에는
집게를 닫힌 상태로 유지하고 놓기 명령을 생략합니다. 기존 요청대로 추종 오차만으로는
중단하지 않으며, 경고가 있으면 최종 `FINISHED WITH WARNING`을 표시합니다.
실제 높이가 부족해도 단계가 진행될 수 있으므로 첫 실물 시험에서는 경로를 확인하세요.

이제 X/Y 속도 목표 40mm/s(20 대비 2배), 가속도 24mm/s²이며 Z 속도 상한은
유지됩니다. 호스트 모의 테스트는 상승 후 회전, 운반 후 하강, 끝에서만 열기,
전체 한 번 실행, 반복 거부, 정지/센서 실패 시 놓기 생략을 확인합니다.

### 연속 상승·하강

`place`의 약 58.4mm 상승은 이제 `XY MOVE` 한 번으로 실행합니다. 50mm 한도에
맞춰 여러 명령으로 나누거나 중간에 정착/보정하지 않습니다. 내부 0.5mm IK
구간은 펄스 계산용이며 전체 이동의 시작/끝에만 가감속합니다. 상승이 끝나면
최종 보정 후 Z 회전, 높이 유지 이동, 연속 하강, 집게 열기를 순서대로 실행합니다.

`pick`의 X/Y 동기 관절 이동은 유지합니다. `place`의 수직 상승·하강도 X/Y 두
모터를 동시에 분배 제어하여 앞뒤 위치를 유지합니다. 각 단계 끝의 제한된 보정과
다음 단계 전 정착 대기는 남아 있지만, 상승/하강 도중 10mm·20mm씩 멈추지는 않습니다.

## 확장 작업 순서: `s` → `run`

시작 사진 자세를 수동으로 맞추고 `s`로 등록한 뒤 `run`을 입력합니다.
이제 별도의 `homez` 입력은 필요 없습니다. Z는 기존 30° 탐색 범위 안에서
홈 스위치에 도달할 수 있는 위치에 있어야 합니다.

전체 순서:

1. Z 호밍 → 첫 건전지 접근/집기/옮겨놓기.
2. 빈 집게 상승 → 두 번째 건전지 위치로 이동 → 내려가 집기.
3. 두 번째 건전지 상승 → 목적지로 이동 → 내려놓기.
4. 빈 집게를 다시 올렸다가 보정된 위치로 내려가 같은 건전지 재집기.
5. 상승 → 두 번째 건전지 반환 위치로 이동 → 내려놓기.
6. 첫 번째 건전지를 다시 집어 원래 받침으로 반환.
7. 빈 집게 상승 → 첫 번째 반환 위치에서 다시 집기 → 옮겨놓기 → 2번부터 반복 (`!`로 중지).

미세 조정용 왕복 명령은 재생하지 않습니다. 각 방문 지점은 연속 상승, 높은 위치에서
XYZ 동시 이동, 연속 XY 하강 세 단계로 합칩니다. 잡기/놓기 때문에 필요한 상승은
생략하지 않습니다. 첫 번째 `place`의 상승에만 요청한 -5mm 후퇴를 합쳤습니다.
다른 구간은 로그의 최종 좌표를 사용하며 새로운 -5mm 오프셋을 중복 적용하지 않습니다.

| 지점 | 앞으로 mm | 위로 mm | Z 출력각 | 근거 |
|---|---:|---:|---:|---|
| 두 번째 집기 | 174.613 | -72.974 | 38.859° | 기록 좌표에서 앞으로 +10mm |
| 두 번째 놓기 | 181.032 | -62.623 | 61.526° | 직전 목표에서 앞으로 1mm |
| 두 번째 재집기 | 182.412 | -67.436 | 놓을 때 각도 유지 | 재집기 구간 Z 펄스 없음 |
| 두 번째 반환 | 174.766 | -60.441 | 38.216° | 재집기 복원값 + 이후 실측 이동량 합산 |

새 구간 운반 높이: 두 번째 집기로 갈 때 -12.027mm(기존 높은 여유),
두 번째 운반 -12.704mm, 재집기 전 상승 -12.718mm, 반환 운반 -7.590mm.
모두 베이스 주 관절 기준 손목 높이입니다. 중간 pos/e가 없어 일부는 로그 복원값이며
실제 집게의 물리적 높이를 직접 측정한 값이 아닙니다.

반환 직전 `xm 5` 두 번은 사용자가 눈으로 거의 안 움직여 보였다고 했지만,
엔코더 출력은 +5.043mm와 +5.011mm였습니다. 이를 0으로 임의 변경하지 않고
합산값을 임시 시험 목표로 사용합니다. 마지막 반환 반경은 원래 두 번째 집기보다
약 10.15mm 앞이었던 기록으로, 이번 집기 +10mm 보정 후에는 비슷한 반경이지만 다음 실물 시험에서 실제 안착 위치를 확인해야 합니다.
사용자는 마지막에 잘 놓였다고 답했지만 이후 이 두 이동의 시각적 불확실성을 추가했습니다.

첫 번째와 두 번째 건전지를 모두 반환한 뒤 자동으로 다음 사이클을 시작합니다.
`!`가 들어올 때까지 반복하며, 사이클 사이 호밍이나 기준 재등록은 하지 않습니다.
각 단계와 목표는 `pickinfo` 및 실행 로그로 확인할 수 있습니다.
`!`/센서 오류/경로 거부 시 이후 단계는 실행하지 않고 현재 집게 명령 상태를 유지합니다.
추종 오차는 기존 요청대로 경고만 표시합니다. 자동 좌표 검사는 장애물을 감지하지 않으므로
처음에는 전체 새 경로와 놓이는 위치를 확인해야 합니다.

최신 조정: X/Y 목표 속도 40mm/s, 가속도 24mm/s²입니다. Z 속도 상한은 유지합니다.
두 번째 최초 집기는 +10mm 보정값을 유지합니다. 놓기와 재집기는 직전 버전에서
각각 뒤로 9mm 보정했습니다. 높이와 Z 목표, 마지막 반환 목표는 유지했습니다. 속도 증가는 장애물 회피를 보장하지 않습니다.

## 첫 번째 건전지 반환과 반복

새 로그의 `RUN FINISHED WITH WARNING; inspect placement` 다음부터 수동 이동입니다.
두 번째 재집기의 추가 Z 회전은 제거했습니다. 놓은 뒤 상승·재접근·하강 동안 Z 펄스를 보내지 않습니다.
첫 번째 재집기는 그 이후 엔코더 이동량을 합산한 F=170.289, U=-72.596mm,
Z≈51.243°입니다. 해당 지점의 pos/e가 없어 복원값이며 Z는 기존 두 번째 반환
목표를 기준으로 합산했습니다. 반환은 마지막 직접 기록 F=185.543, U=-62.871mm,
Z=27.142°를 사용합니다. 조정용 왕복과 반복 개폐는 재생하지 않습니다.
재집기 운반 높이 -15.570mm, 반환 운반 높이 -17.718mm를 사용합니다.

최신 동작은 시작 자세로 복귀하지 않습니다. 첫 번째 최종 반환 Z는 27.142°에서
26.442°로 -0.7° 보정했습니다. 반환 후 집게를 열어 둔 채 U=-17.718mm까지 올리고,
그 반환 위치로 다시 내려와 첫 번째 건전지를 집은 뒤 목적지로 옮깁니다.
두 번째 건전지도 반복 사이클에서는 처음 집기 목표 대신 직전 반환 목표를 사용합니다.
X/Y 목표 속도는 20→40mm/s, 가속도는 12→24mm/s²로 변경했습니다.
Z 속도와 최소 펄스 주기는 유지하므로 모든 구간의 실제 속도가 두 배인 것은 아닙니다.

최초 사진 시작 자세에서 `s` → `run`을 한 번 입력합니다. 최초 Z 호밍 후 두 건전지를
옮기고 반환하는 순서를 `!` 입력 전까지 계속 반복합니다. `!` 또는 센서/경로 오류는
반복을 끝내고 펄스를 멈추며 현재 집게 상태를 유지합니다. 각도 추종 경고는 기존처럼
출력하고 진행합니다. 완료 로그는 실제 파지 성공을 보장하지 않습니다.
중지 후 `run`은 임의 위치 재개 명령이 아닙니다. 팔과 건전지를 처음 배치로 복구하고
사진 시작 자세에서 `s` → `run`으로 다시 시작합니다. 전원을 끄고 수동으로 팔을
움직였다면 반드시 기준을 다시 등록합니다.


## 반복 Z 고정 보정과 대기 단축

첫 사이클의 Z 목표는 그대로입니다. 2회차 시작부터 모든 자동 방문 목표에 +0.4°를
고정 적용합니다. 3회차 이후에도 +0.4°이며 누적하지 않습니다. 집게를 들어 올린 뒤
XYZ 이동에서 보정하며 호밍 영점/엔코더 카운터를 변경하지 않습니다.
새 `run`은 다시 첫 사이클 보정 0°부터 시작합니다.

모터 속도/가감속과 XYZ 경로는 유지합니다. 이동 후/보정 후 엔코더 정착 대기를
200ms에서 50ms로, 동시 이동 DIR 준비를 20ms에서 100µs로 줄였습니다.
집게는 실제 각도 명령이 바뀐 뒤 500ms를 확보하되 계획·출력에 이미 사용한 시간을
차감하며 같은 열기/닫기 명령에는 대기를 다시 시작하지 않습니다.
시리얼은 115200bps로 변경하여 로그 전송에 따른 정체를 줄였습니다.
`!` 처리와 기존 센서/경로 중지 처리는 유지됩니다. 실물 반복 오차와 정착 시간은
업로드 후 확인해야 하며, 이 고정 보정이 기계적 누적 오차의 원인을 해결하는 것은 아닙니다.

최신 위치 조정: 두 번째 놓기 반경을 179.432→180.032mm로 +0.6mm 보정했습니다.
재집기 XY 좌표와 높이는 그대로이며, Z는 놓을 때의 실제 각도를 유지합니다.
속도·가감속·대기 단축 설정은 유지합니다.


## 빈 집게 증속과 두 번째 반복 위치 보정

두 번째 놓기 반경은 180.032→181.032mm로 1mm 더 앞으로 옮겼습니다.
2회차 첫 재집기부터 모든 방문 목표의 앞으로 좌표에 +1.2mm를 고정 적용합니다.
3회차도 +1.2mm이며 누적하지 않고, 새로운 run은 보정 0으로 시작합니다.
이는 이동 전에 상대 명령만 넣어 다음 절대 목표에서 취소되는 것을 막기 위한 처리입니다.
기존 Z +0.4° 고정 보정과 두 번째 재집기 중 Z 회전 없음은 유지합니다.

자동 운반에서 집게가 열림(100°) 명령 상태이면 X/Y 목표 80mm/s, 가속도 96mm/s²,
XY 최소 반주기 750µs를 사용합니다. 닫힘 또는 중간 각도는 기존 40mm/s,
24mm/s², 1500µs를 사용합니다. 수동 이동과 저속 끝점 보정은 기존 설정입니다.
Z 및 호밍 속도는 유지하므로 Z 동시 이동 구간은 해당 속도 제한을 받습니다.
이 속도는 실측 최대값이 아닌 다음 시험 목표이며, 실제 파지 센서 없이 명령 각도로
부하 상태를 구분합니다. 사용법은 115200bps, 시작 자세에서 s → run, 중지는 !입니다.


## 최신 속도 설정

직전 버전 대비 자동 동작의 부하 상태별 속도를 변경했습니다.

| 구간 | 직전 | 현재 목표 |
|---|---:|---:|
| 건전지 잡은 상태 XY | 40mm/s | 80mm/s (2배) |
| 빈 집게 XY | 80mm/s | 240mm/s (3배) |
| 잡은 상태 Z 펄스 상한 | 125펄스/s | 250펄스/s (2배) |
| 빈 집게 Z 펄스 상한 | 125펄스/s | 약 375펄스/s (3배) |
| Z 호밍 탐색/후퇴 | 125펄스/s | 250펄스/s (2배) |

기존 가감속 계산 방식을 유지해 XY 가속도는 잡은 상태 96mm/s²,
빈 집게 864mm/s²입니다. 열린 각도 100°만 빈 집게로 분류하고 중간 각도는
잡은 상태 속도를 사용합니다. 이는 파지 센서 판정이 아닌 명령 상태입니다.
수동 조그와 저속 끝점 보정은 그대로이며 자동 운반 및 homez에 적용합니다.
실제 속도는 Mega 계산시간, I2C, 펄스 제한과 가감속 때문에 목표보다 낮을 수 있습니다.
기계의 보장된 최대 속도는 아니므로 첫 실물 실행에서 추종 오차와 진동을 확인합니다.
호밍 탐색 범위·후퇴 거리·타임아웃·스위치 감지와 ! 중지, 작업 위치 보정은 유지합니다.


## 반복 위치 보정 최신값

2회차 첫 건전지 재집기부터 모든 집기·놓기 목표에 앞으로 **+0.8mm**,
위로 **-1.0mm**를 고정 적용합니다. 기존 앞으로 +1.2mm 보정을 대체합니다.
3회차 이후에도 같은 값이며 누적되지 않고, 새 run의 첫 사이클은 보정 0입니다.
운반 중 상승 높이는 기존 값을 유지하여 건전지를 넘는 높이는 낮추지 않습니다.
Z +0.4° 반복 보정, 재집기 구간 Z 회전 없음, 부하별 속도와 호밍 속도는 유지합니다.
